# MoneyMate Homepage

A responsive, light-theme personal money-management landing page and working dashboard demo.

## Run
Open `index.html` in a browser. No build step is required.

## Included
- Responsive homepage
- Light-first visual system
- Hero section
- Feature cards
- How-it-works section
- Working budget calculator
- Spending/savings dashboard
- Dynamic money insight
- Reset demo button
- Mobile navigation
- Smooth-scroll CTAs

## Next production steps
Connect authentication, a real database, secure financial-data integrations, bill reminders, and a backend API. Avoid storing bank credentials directly in the frontend.
